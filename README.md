# 形迹 · 认知实验室

中文认知练习的本地交互原型。React + TypeScript + Vite + SVG；无需账号或后端。

## 发布与源码

- GitHub（私有源码）：https://github.com/vryTfmcat/cognition-lab
- Sites：https://xingji-cognition-lab.vrytfmcat.chatgpt.site （首次发布为仅所有者可访问）
- Netlify 项目：https://app.netlify.com/projects/xingji-cognition-lab （部署状态见发布记录）

两个托管站点运行同一套前端，各域名的浏览器记录相互独立。发布不会自动收集参与者结果，仍使用本机浏览器保存和JSON/CSV导出。

Netlify 构建命令为 `npm run build`，发布目录为 `dist`。本地 `.netlify/`、环境变量、QA截图和结果不纳入源码仓库。Sites 的身份保存在 `.openai/hosting.json`。

## 启动

在此目录打开 PowerShell：

```powershell
npm.cmd install
npm.cmd run dev -- --port 5173
```

打开 http://127.0.0.1:5173/ 。原型通过本地 HTTP 运行，不直接双击 index.html。

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run preview -- --port 4173
```

若要由同一局域网手机访问，运行 `npm.cmd run dev -- --host 0.0.0.0 --port 5173`，使用电脑局域网 IP。此命令需你自行允许本地防火墙对应访问；不等同于公网部署。公网地址见上方发布信息。

## 内容

- 三题快速体验：沿用已有材料；策略更新为多选，three-memory-v1.1。
- 十二题：新题 operations-new-v1.0，记忆/变换/关系迁移/可逆性各3题。规则明确，不覆盖历史版本。
- Unicode：30个字符，6题序列再认，结束后收集熟悉度，unicode-pilot-v1.0。
- 三种SVG家族：polygon / smooth / mixed；混合9题各3题；单类6题。
- 练习作答后反馈；测试最后反馈。记忆方式在观察/作答时选填，不强制停留在单独页面。冻结测试种子20261014；练习新种子。
- 本地进度、最近20轮历史、JSON/CSV导出、下载受限时可复制文本。

## 工程与接口

`src/core.ts`：版本化随机算法、生成器、几何校验、任务/刺激/轮次类型与导出。
`src/bank.ts`：固定题目、几何操作、轮次配置。
`src/main.tsx`：答题状态流程与界面。
`src/unicode.json`：仅保留字符身份、字形标签、来源版本与字体信息。

生成器使用mulberry32-v1和shape-v1.1.0。参数、控制点、SVG路径、选项映射与几何校验摘要进入JSON。所有选项保持同坐标系、尺寸、方向、线宽和顶点数；图形难度可选简单（3处、12单位）、标准（2处、8单位）、困难（1处、4单位），默认简单。每档保持同顶点数、颜色、线宽及坐标系；简单/标准保留一个凹口及相邻点不变，确保凹多边形家族仍有凹口。当前难度尚未经真人校准。

轮次schemaVersion=1.0。稳定选项ID判分。刷新/切屏/题内返回首页会标记中断；恢复重做同题并累计重复暴露。观察/作答时选填的勾选和描述会保存草稿；计时结束不清空输入或强制移走焦点。中断、重复暴露、辅助题不进入正常均值；若整轮报告使用或可能使用辅助，整轮均值不展示。

## 字体与来源

NotoSansSymbols2、NotoSansMath、NotoSansArmenian、NotoSans完整字体本地随包，不使用在线字体请求。字体版本与SHA256保存在字符清单。SIL Open Font License 1.1：public/fonts/OFL.txt；来源 https://github.com/notofonts/noto-fonts 。原文件保持不修改。

30字符由Unicode 17已有2000精选与全码表按类别提取（数学/亚美尼亚材料从全码表补足）。脚本检查独立字符和字体cmap覆盖；全码表补入只限数学运算符和亚美尼亚区块，均不含emoji或组合附加符。prepare-unicode.py用于维护时重新提取，需要Python/fontTools和原资料路径；运行网站不需要Python。字符实际字体版本见清单，不将陌生文字预设为参与者不熟悉。

来源为原Obsidian项目的四份需求文档、关联三题问卷、答案校验、练习索引、Morgan论文笔记及70_unicode材料。不包含个人读音、输入码、联想图谱、密码或原始笔记路径。

## 数据与限制

浏览器只写本站 localStorage，不上传答案。JSON含匿名编号、题目版本、材料/选项、选择、计时、策略、辅助、中断、显示尺寸与熟悉度。CSV一题一行，UTF-8 BOM，文本正确转义。下载文件自行备份，勿放公开仓库。

非标准化探索原型，不用于诊断、智力评级或心理测量。答案在前端源码中。不同家族难度不可直接比较。实际微信、iOS/Android字体视觉差异、移动网络访问和下载仍待真人设备验收。

## 结束未完成的实验

“返回首页”暂存进度；如果不想继续本轮，可在实验页上方或首页未完成提示处点击“结束本轮”。确认后只移除本轮未完成进度，已完成历史保留。有已答题目时可先导出JSON，下载受限可复制文本。

也可直接点击另一项实验，在弹窗选择“结束并开始新实验”。选择“暂不结束”或Escape会保留原进度；观察/作答阶段打开弹窗时会暂停并标记中断，继续时重做当前题。

## 独立操作样例

首页“操作样例 · 不计分”提供单独入口。正式实验同意参与后直接进入该实验第一题，不再强制经过共用样例。样例完成后返回首页，不自动开始实验，也不创建正式轮次或写入成绩。旧版本停在sample阶段的进度，刷新后回到所属实验说明页，保留任务和已答记录。


## 难度与选填记忆方式（更新）

在首页“图形再认实验”通过0%—100%滑动条连续调节难度后再开始轮次（默认0%，百分比越高选项越相似）；既有轮次沿用原材料，结束后才能应用新的难度。观察时间仍为10秒。JSON/CSV保留difficulty、生成器参数、runnerVersion=runner-v2-inline-optional、strategyTiming=during-observation-or-answer，以区分旧版作答后填写的数据。参数难度尚待真人校准。

记忆方式位于记忆材料下方，可在倒计时期间填写，材料自动隐藏后也可补充；也可全部留空，选择答案即继续。不填写记录为空，不视为猜测。


## 自选题数与明确反馈（2026-10-14）

各入口卡片可选本轮题数。固定题库：快速体验1—3题、表征与操作1—12题、Unicode1—6题；图形实验1—30题。混合家族按题数尽量均衡分配（三的倍数时完全均衡）；固定题库缩短轮次时从题库均匀取样，不重复扩充题目。开始前显示总题数，轮次开始后固定，恢复继续原题数。JSON保留questionCount及完整tasks，CSV增加question_count。测试批次更新为frozen-20261014-v4。

练习反馈标题直接显示“✓ 回答正确”或“✕ 回答错误”，并在所选材料处标注正确/错误。测试模式仍在轮次结束时反馈。

题数控件采用“− / 数字输入框 / +”步进器。参与者可以直接键入范围内的任意整数，也可以用按钮或键盘方向键每次调整1题。失焦、按回车或开始实验时，空值、小数和越界值会自动修正为该实验允许的整数范围。
